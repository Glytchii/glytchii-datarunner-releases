# Glytchii Datarunner releases

Public installer downloads for **Glytchii Datarunner**, a Star Citizen commodity
price reporter for [UEX](https://uexcorp.space).

- Get the latest installer from the
  [Releases](https://github.com/Glytchii/glytchii-datarunner-releases/releases/latest)
  page.
- Each release includes `GlytchiiDatarunnerSetup.exe` and a `latest.json`
  manifest (version, notes, installer URL, and sha256).
- This repository does **not** contain application source code, app tokens,
  secret keys, or other credentials.

The app checks for updates over HTTPS at:

`https://github.com/Glytchii/glytchii-datarunner-releases/releases/latest/download/latest.json`
